# ESP32 Linux CLI

Control ESP32 from Linux terminal — pure C++ without Arduino IDE.

## Quick start

```bash
git clone https://github.com/dostievib-oss/esp32-linux-cli
cd esp32-linux-cli
idf.py flash
idf.py monitor

##Commands (coming soon)
led on / led off - control built-in LED
status - show system info

##Requirements
ESP32 board
Linux
USB cable
